How the Agent Loop Works

1

Cron triggers at 7am daily

node-cron wakes up the orchestrator. Kicks off the daily marketing run.

2

Research Agent gathers context

Firecrawl scrapes competitor profiles (Qomfort, Le Bon Shoppe). Checks Google Trends for niche keywords. Pulls yesterday's Instagram performance data.

3

Claude receives full context + tools

You pass Claude: competitor activity, your recent performance, content calendar, brand guidelines. Claude has access to tools it can call.

4

Claude decides what to do and calls tools

Claude might call: get_trending_hashtags → generate_caption → schedule_post. Or decide today isn't a good posting day and just log insights instead.

5

Post goes live on Instagram

The posting tool hits the Meta Graph API. Order notification sent to you + Cem via email/Slack.

6

Analytics saved to SQLite

Likes, reach, profile visits, link clicks saved. Next day's agent uses this to make smarter decisions. Feedback loop builds over time.

Why Claude SDK tool use is perfect here: You define a set of tools (functions your code can run). Claude reads the context and autonomously decides which tools to call, in what order, with what arguments. No hardcoded if/else logic — Claude reasons about what the brand needs today.

Build Order

Phase 1

Research + Content Generation

Week 1 — ~2 days
  • Set up repo, TypeScript, Anthropic SDK
  • Build Firecrawl tool — scrape Qomfort + Le Bon Shoppe IG profiles daily, store in SQLite
  • Build trends tool — Google Trends API for "slouch socks", "birkenstock socks" keywords
  • Build strategy agent — Claude receives competitor data + trends, outputs: content theme, caption, 30 hashtags, best posting time
  • Output saved to SQLite content calendar table. Log to console for now.
Phase 2

Instagram Auto-Posting

Week 2 — ~2 days
  • Set up Meta Developer App + Instagram Business Account
  • Build instagram.ts tool — post image with caption + hashtags via Graph API
  • Connect to orchestrator — Claude calls post_to_instagram tool when content is ready
  • Add notify.ts — email/Slack alert to you + Cem when post goes live
  • Test full loop end to end with a real post
Phase 3

Analytics Feedback Loop

Week 3 — ~2 days
  • Build analytics.ts — pull Instagram Insights (reach, likes, profile visits, link clicks) 24h after each post
  • Save to SQLite posts table with performance scores
  • Update orchestrator context — Claude now sees "last 10 posts + their performance" when making decisions
  • Claude starts learning: "carousel posts of cream colourway on Tuesdays get 3x reach"
Phase 4

TikTok + Dashboard

Month 2
  • Apply for TikTok Content Posting API access (requires business verification)
  • Build tiktok.ts tool once API access granted
  • Build simple Next.js dashboard — view content calendar, post history, performance charts
  • Cem can see everything in one place, override any scheduled post
